# Changelog

## 2026-05-21 — Atualização de layout e documentação

- Visual: fundo musical em camadas, gradientes suaves nas superfícies, cabeçalho integrado ao visual do hub.
- Acessibilidade: suporte explícito a `prefers-reduced-motion` e contraste ajustado para modo escuro.
- Documentação: adição da seção "Elementos Musicais no Layout" no `README.md` com orientações sobre notas, claves, tempo/compasso, partitura e boas práticas.
- Relatório: `relatorio.html` atualizado com explicação sobre tempo/notação na seção de pauta desenhada.
- Service Worker: atualização do `CACHE_NAME` (`piano-map-v19`) para forçar renovação do cache e publicação das mudanças.
- Commit e publicação: alterações commitadas e enviadas para `origin/main` no GitHub; site no GitHub Pages atualizado.

> Observação: se os usuários ainda virem a versão antiga, recarregue com cache-bypass (Ctrl+Shift+R) ou abra em janela anônima; também há instruções no README para validar o layout.
